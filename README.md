# energy_llm

Research framework for studying energy-based signals in LLM internal states, with emphasis on MLP memory banks, Hopfield-style retrieval, hallucination analysis, and cross-model experimentation.

## Structure

- `src/energy_llm/` main source code
- `configs/` experiment and model configs
- `data/` datasets and processed files
- `artifacts/` cached banks, hidden states, retrievals, plots
- `runs/` reproducible experiment outputs
- `scripts/` local and cluster execution scripts
